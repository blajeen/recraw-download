# Recraw

Áudio, tela e ideias. Programa gratuito para Windows que reúne gravação de microfone e som do computador, captura da tela inteira e um quadro de anotações com imagens e recorte.

O programa usa Microsoft Edge WebView2. O instalador prepara esse componente se necessário; a versão portátil precisa dele já instalado. O uso diário funciona offline. Aplicativo e instalador ainda sem assinatura digital.

Esta é uma versão inicial. Faça o teste de áudio antes de uma reunião importante. A transcrição e o resumo são feitos depois, em outra ferramenta.

Este repositório distribui os arquivos de instalação; não contém o código-fonte do aplicativo. Os créditos das dependências acompanham os pacotes.
