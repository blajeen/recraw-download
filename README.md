# Recraw

Áudio, tela e ideias. Programa gratuito para Windows com gravação de microfone e som do computador, captura da tela inteira, quadro de anotações e **transcrição local em português**.

Os dois pacotes já incluem Whisper e o modelo Base. Não é necessário instalar Python, cadastrar conta, fornecer chave de API ou baixar um modelo para transcrever. A transcrição funciona offline e o áudio permanece no computador.

Na versão portátil, **extraia todo o ZIP e mantenha a pasta `whisper` ao lado de `Recraw.exe`**. Leve o pacote completo para outro computador. O programa precisa do Microsoft Edge WebView2; o instalador prepara esse componente se necessário, e essa preparação pode precisar de internet.

## Transcrição

Após terminar a gravação, abra **Transcrição**, encontre o áudio ou vídeo e clique em **Transcrever**. O texto é salvo ao lado do original, com edição, copiar e exportar TXT. Há progresso e cancelamento. A gravação original não é alterada.

O modelo incluído ocupa cerca de 148 MB, e por isso o pacote é maior que o da versão anterior. A velocidade depende do processador e do tamanho do áudio. Revise nomes, números e falas sobrepostas. O Recraw não gera resumo nesta versão.

Aplicativo e instalador ainda sem assinatura digital. Esta é uma versão inicial: teste o áudio antes de uma reunião importante.
